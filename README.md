# NanoPro 2.0

### An Economical, Benchtop, and Fully Automated Microscope for High-Resolution Single-Molecule Localisation Microscopy

**NanoPro 2.0** is a compact, economical, fully automated, and open-source microscope designed for high-resolution single-molecule localisation microscopy (SMLM), including DNA-PAINT and dSTORM.

Building on the original NanoPro platform, NanoPro 2.0 combines a compact optical architecture (45 × 30 cm footprint), four excitation wavelengths, high-sensitivity sCMOS detection, active focus stabilisation, and precision sample positioning. A modern graphical user interface (GUI) integrates instrument control and image acquisition, simplifying advanced super-resolution microscopy.

NanoPro 2.0 achieves sub-nanometre fitted localisation precision and supports high-resolution imaging of biological structures.

## CAD Files

This repository contains the **CAD files for all custom components requiring CNC machining** to construct NanoPro 2.0.

These files provide the geometries and dimensions necessary to manufacture the custom mechanical components and reproduce the microscope's mechanical architecture.

## Interactive 3D Assembly

The complete NanoPro 2.0 assembly is available as an interactive 3D model.

**[Explore the Interactive 3D Assembly](https://a360.co/4eC8b1D)**

The model allows users to:
- Rotate, zoom, and inspect the complete microscope.
- Explore individual optical and mechanical components.
- Examine the positioning and arrangement of components.
- Understand the instrument's construction before manufacturing and assembly.
